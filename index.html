¿Quieres ver un nuevo ejemplo de lo que puedes hacer con JavaScript?

Con JavaScript puedes cambiar el estilo de un elemento de HTML.

Vamos a explicar paso a paso lo que hace el pequeño programa anterior.

Todas las instrucciones están incluidas dentro del botón. Tenemos tres partes diferenciadas:

  • onclick: aquí indicamos que el código se ejecutará al presionar el botón.
